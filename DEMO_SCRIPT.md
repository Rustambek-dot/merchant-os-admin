# Demo Script — Merchant OS (4 минуты)

1. **Landing** (20с) — монохромный минимализм, grid-фичи.
2. **Dashboard** (40с) — выручка 7 дней, AOV, конверсия, последние заказы.
3. **Orders** (60с) — пайплайн: нажать «→ fulfilled» у оплаченного заказа, статус меняется; Refund в один клик; фильтры и поиск.
4. **Products** (70с) — ключевой момент:
   - Раскрыть товар → варианты с по-SKU остатками (красный «0», жёлтый «4»)
   - Нажать **Generate with AI** → описание появляется в карточке
5. **Customers** (50с) — LTV-таблица; **Analyze Reviews** → темы с тональностью и action items («добавьте size chart — главная причина возвратов»).
6. **Discounts** (30с) — создать промокод вживую, usage-бары.
7. **Settings** (20с) — Stripe в mock mode, доставка, команда.
8. **Финал** (10с) — тёмная тема, мобильный вид.
